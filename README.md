# 🌐 Family Web Stream

Interface Web IPTV universelle haute performance, conçue pour **PC, Mac, Smart TV (LG webOS, Samsung Tizen) et Mobiles**.

---

## ✨ Points Clés

- **Pilotage 100% Télécommande (D-Pad)** : Prise en charge native des flèches, de la touche OK, des touches de couleur et des boutons multimédia (Play/Pause, Avance, Recul, Chaine+/Chaine-).
- **Compatible LG webOS (Magic Remote) & PC (Souris)** : Détection intelligente du curseur — si vous bougez la souris, le pointeur s'affiche ; dès que vous appuyez sur une flèche de télécommande, le pointeur s'efface et le halo doré de navigation TV prend la main.
- **Plein Écran Automatique** : Dès la première action ou clic sur le code PIN, l'application masque l'ensemble des barres de navigation du navigateur pour une immersion totale.
- **Lecteur Vidéo Web Avancé** : Intégration de `mpegts.js` pour la lecture fluide des flux directs MPEG-TS sans plugin externe, combinée au décodage HTML5 natif pour le HLS et les films VOD (MP4).
- **Navigation Fluide (60 FPS)** : Interface réactive sans framework lourd, optimisée pour un affichage instantané des catégories, chaînes et affiches.

---

## 🚀 Démarrage Rapide

Double-cliquez simplement sur :
```text
Lancer-Web.bat
```
Le serveur local démarre sur le port `8090` et ouvre votre navigateur en mode plein écran TV (1920x1080).

### 🔑 Code de Test Immédiat
Sur l'écran d'accueil, tapez le code PIN :
```text
0000
```
Cela charge immédiatement une sélection de démonstration (Live TV & VOD) pour tester l'ensemble de la navigation, du zapping et des commandes sans avoir besoin de connecter un serveur IPTV.
